# oshish.tech

My personal portfolio: projects, writing, and a few things I'm working toward.

- **Single page, no build step.** Everything lives in `index.html`.
- **Pages:** Home, Work, Writing, About and Craft, plus a page for each project and post.
- **Light and dark mode:** pull the cord in the top-right corner.

## Run it locally

```bash
python -m http.server 4321
```

Then open http://localhost:4321.

## Editing content

Projects, posts and the Germany timeline are short lists near the top of the script in `index.html`: `PROJECTS`, `POSTS` and `JOURNEY`.
